# Scholarship Management Portal

A Flask-based web application developed to simplify the scholarship application process for students.

## Project Overview

The Scholarship Management Portal allows students to explore scholarships, check eligibility criteria, manage their profile, upload required documents, submit scholarship applications, and track application status.

## Features

- View available scholarships
- Check eligibility criteria
- Manage student profile
- Upload required documents
- Submit scholarship applications
- Track application status

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
